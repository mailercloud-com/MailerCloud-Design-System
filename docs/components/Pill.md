The Pill is a short label in a fully rounded shape, used for options, phases and lane names.

- Shape `radius-pill`; type `t-label` (24px on slides, weight 600); padding 6–8px vertical and 18–22px horizontal.
- Fills: `bg-lime` or `bg-sky` for neutral tags, `bg-green` for "unchanged" or "fastest start", `navy` with `bg-lime` text for the new or emphasised route. Text is `ink`, except `positive-ink` on `bg-green` and `bg-lime` on `navy`.
- Lane labels in diagrams are uppercase with 1px letter spacing and a 3px border in the fill colour.
- One to five words. The consumer provides the text; never use a pill for a full sentence.
